# 《引金据典》——有据可依的银行智能体

2026 深圳国际金融科技大赛（FinTechathon）· 国内赛道 · 人工智能赛道（银行 AI 智能体）参赛作品。

> 智能体「小微」是微众银行 AI 助手。用一句自然语言，替你在安全边界内管好钱——查账、理财、转账、管卡、退订阅。覆盖五大场景 + 跨场景联动，每一步都有数据可溯、有权限边界。
>
> 作品版本：v1.0

---

## 目录结构

```
backend/              后端（FastAPI）
  app/main.py           入口与全部对外接口
  app/orchestrator/     编排层：意图识别、任务规划、确认卡状态机、回复生成
  app/tools/            能力层 6 类工具：transfer/bill/wealth/card/subscription/profile
  app/policy/           策略层：权限分级 L0-L3、确认凭证、审计留痕
  app/guard/            防线层：注入检测、幻觉防护输出校验
  app/data/             资金事实库（SQLite）与演示数据
  app/permissions.py    行为级权限调节（15 个行为独立设 L0-L3）
  app/llm.py            双模式：API Key 大模型调用 + 规则聊天兜底
  app/i18n.py           中文字段映射
  tests/                pytest 用例（60 条）+ REPORT.md 测试报告
frontend/             前端（React + TypeScript + Vite，纯 CSS 深色金融主题）
  src/XiaoWei.tsx       Q 版智能体「小微」SVG 形象
  src/ChatView.tsx      对话页（富卡片：确认卡/账单/趋势/持仓/转账/流水）
  src/DataView.tsx      资金总览看板
  src/ProfileView.tsx   习惯画像（行为统计 + 推荐）
  src/SecurityView.tsx  安全中心（行为权限调节 + 审计筛选）
docs/                 设计文档（宪法/PRD/架构/安全设计/红队自审）
scripts/              seed.py 灌数据、demo.sh 一键演示、md2docx.py 文档转换
```

## 环境要求

- Python ≥ 3.10
- Node.js ≥ 18（前端）
- 无需数据库、无需外部 API Key（未配置时自动运行规则模式）

## 部署说明（五条命令完整启动）

```bash
# 1) 安装后端依赖
cd backend && python -m pip install -r requirements.txt

# 2) 灌入演示数据
cd .. && python scripts/seed.py

# 3) 启动后端（端口 8000）
cd backend && python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# 4) 安装前端依赖并启动（端口 5173，另开终端）
cd ../frontend && npm install && npm run dev

# 5) 浏览器打开 http://localhost:5173/
```

验证：`http://127.0.0.1:8000/health` 返回 `{"ok": true, "app": "引金据典", "version": "1.0"}`；接口文档见 `http://127.0.0.1:8000/docs`。

一键演示（灌数据 + 跑测试 + 启动后端）：

```bash
bash scripts/demo.sh
```

## 双模式说明

| 模式 | 触发条件 | 能力 |
|---|---|---|
| 规则模式（默认） | 未配置 API Key | 关键词意图识别 + 模板话术 + 基础闲聊（问候/感谢/能力介绍等），五场景全部可演示 |
| 大模型模式 | 在界面左下角「规则模式 → 配置」填入 API Key（OpenAI 兼容接口） | 大模型语义理解与对话 |

两种模式共用同一套策略层与工具层，安全边界不因模式切换而改变。切换入口：前端左下角模式芯片。
