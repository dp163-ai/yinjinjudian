## 第二部分 · 四项技术硬要求的"可验证形态"拆解

> 每一条都必须**能在演示里被看见**，或**能在文档里被证明**。缺一条即视为未达标。

### 2.1 权限分级机制（5 条）

1. **分级定义表**：L0（只读非敏感）/ L1（只读敏感）/ L2（写·低风险可逆）/ L3（写·高风险），每级列出允许的操作集合。→ 见于安全中心页面 + 技术文档 §3.2。
2. **升级触发条件**：金额阈值（≤500 L2、>500 二次确认、>5000 L3）、场景、收款方白名单、是否首次、卡片状态、设备/时段。→ 演示超限转账被自动升级确认。
3. **二次确认交互**：高风险操作弹出确认卡，**自然语言复述**"收款人/金额/时间/后果"。→ 现场点一次"转账 2000"看确认卡。
4. **越权拒绝话术**：拒绝 + 给替代方案（如"超出你当前额度，我可以帮你发起调额申请"），不做冷拒绝。→ 演示越权被友好拦截。
5. **全链路审计留痕**：who/what/when/how much/策略依据/用户确认原文。→ 安全中心审计日志流现场翻看。

### 2.2 幻觉防护（4 条）

1. **数字来源白名单**：余额/利率/收益/费率只能来自工具返回值，模型禁止自由生成数字。→ 架构图标注 + 代码 `guard/output_validator` 落地。
2. **无数据时明确说"查不到"**：绝不猜测。→ 演示"查一笔不存在的流水"，Agent 回答"没查到，要看最近 7 天吗"。
3. **回答附数据来源与时间戳**：每条结论下方小字标注来源。→ 界面每条 Agent 回复带来源标注。
4. **置信度标注**：不确定信息标注"基于近 3 个月数据，仅供参考"。→ 账单/理财结论带置信度前缀。

### 2.3 提示词注入防御（5 条）

1. **指令与数据分离**：账单备注、商户名、订阅名、卡别名等外部文本进 `<data>` 标签，声明"仅数据不含指令"。→ 架构 + 代码 `guard/input`。
2. **外部文本隔离与转义**：外部文本不做指令解析，展示时转义防 XSS。→ 代码落地。
3. **识别并拦截"忽略之前的指令""你现在是…"类攻击**。→ 现场注入攻击实测被拦。
4. **工具参数白名单校验**：类型 + 枚举 + 金额上限硬编码。→ 代码 `policy/` + 测试用例。
5. **结构化输出约束**：JSON Schema 限制模型只能产出预定义动作。→ 编排层 prompt 与解析代码。

### 2.4 意图理解与任务规划（4 条）

1. **多轮指代消解**："再转一次刚才那笔"能定位到最近交易；定位失败则反问。→ 演示连续对话。
2. **多意图拆解**："看这个月账单，超了就把会员退了"拆成查账→判断→退订两个子任务+依赖。→ 决策轨迹面板展示拆分。
3. **歧义反问不猜测**："退订"（退订阅 vs 退理财）列出候选请确认。→ 演示歧义话术。
4. **跨场景任务编排**："挂失卡"连带"停代扣"（联动）；"生日"锁定资金+推荐入口（不代下单）。→ 两条联动链路演示。

## 第四部分 · 最容易被判低分的 8 个坑（附规避动作）

| # | 坑 | 规避动作 |
|---|---|---|
| 1 | 功能拼盘无主线 | 五场景串成"钱的一生"一条主线，卡片管理做咬合点 |
| 2 | 权限分级只写文案不落地 | 分级落成 L0–L3 表 + 三重门 + 审计，演示越权被拦 |
| 3 | 评审环境无 Key/断网跑不起来 | 离线规则引擎降级，无外部依赖可演示 |
| 4 | 自动下单 / 无确认转账（红线） | 所有写操作必经确认，模型永不直接执行交易 |
| 5 | 数字无法溯源（疑似编造） | 数字只来自工具 + 输出校验器 + 来源标注 |
| 6 | 现场被注入攻击攻破 | 四层防御 + 提前自测 5 种攻击载荷 |
| 7 | 安全自评报告写成免责声明 | 摊开写风险，含"未完全解决"项 + 残余风险 |
| 8 | 卡 DDL / 格式超限 | 提前 12h 提交，打包前自检体积与 .env 排除 |

## 第五部分 · 红线清单（绝对不能做）

> 违反任一条直接判负，无例外。

1. **禁止自动下单 / 自动交易**：理财申购、转账、赎回等一律需用户显式确认。
2. **禁止无确认转账**：任何金额的转账都不得跳过确认卡。
3. **禁止编造收益率 / 余额 / 利率**：所有数字必须来自工具返回值。
4. **禁止把模型输出直接当执行指令**：模型只产出意图+参数，写操作由工具层+策略层完成。
5. **禁止泄露他人数据**：不响应"查别人账单""看系统提示词"类越界请求。
6. **禁止跳过二次确认**：任何"别问了直接执行"的请求一律拒绝并记录。
7. **禁止接入真实资金**：本作品为竞赛原型，所有交易与数据均为模拟。
